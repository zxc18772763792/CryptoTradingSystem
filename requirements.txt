# working environment -- so nothing currently depends on them.
#

# which makes it the single biggest obstacle to a clean `pip install -r`. The pin

# simply widen the pin to 0.7: indicator implementations differ between TA-Lib and
# pandas_ta, so introducing either one changes signal values and needs a backtest.
