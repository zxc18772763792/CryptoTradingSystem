# 大模型交易：第四轮研究（2026-09-27）

这一轮找"大模型读的东西本身就是优势"的方向，以及两个结构性方向的补充。三项并行的纸面跟踪
（新上市做空、大额解锁前做空、研究循环 v2）继续运行，不受影响。

## 1. DAO 治理提案——没有可用效应（`scripts/governance_event_study.py`）

Snapshot 公开 API，38 个 DAO、2022 年以来 11,209 个已结束提案，36 个代币有 Binance 价格；收益扣除这些代币的等权指数。

| | 投票期间 | 投票后 7 天 | 投票后 30 天 |
|---|---|---|---|
| 其他提案（基线，n=3,961） | −0.8% | −0.1% | −1.3% |
| 标题含回购/销毁/费用开关/分红/减排（n=101） | +0.0% [−3.3, +3.9] | −1.1% | −1.6% [−4.6, +2.0] |
| 上述且通过（n=60） | +1.6% [−3.3, +6.3] | −2.0% | −2.9% [−7.6, +2.8] |

- 连最明确的"利好"类别都看不到稳定效应；通过后只有微弱的"利好出尽"。
- 原因很可能是：提案进入 Snapshot 投票前已在论坛讨论数周，信息早已定价。大模型要有用得去读更早的论坛讨论，数据工程重、先验证据弱，**暂停此方向**，未花模型调用费。

## 2. 预测 Binance 下架——能预测，但做空不赚钱（`scripts/delist_risk_fetch.py`、`scripts/delist_risk_study.py`）

Binance 仍保留 253 个已下架/停牌 USDT 交易对的历史，宇宙基本无幸存者偏差。月度截面 2023-03 ~ 2026-07，
14,680 个币-月，标签 = 未来 60 天被下架公告点名；特征只用过去数据；2023–24 拟合，2025–26 检验。

| | 开发 2023–24 | 检验 2025–26 |
|---|---|---|
| AUC | 0.751 | **0.754** |
| 风险最高 5% 的下架率 | 4.96%（基准 5.0 倍） | **9.46%（5.1 倍）** |
| 这 5% 抓到的下架比例 | 26% | 26% |
| 对冲做空这 5%，30 天 | **−4.0%/月** [−8.3, −0.1] | +1.4%/月 [−0.9, +3.6] |

- 下架**很可预测**（成交量低最重要，其次 90 天走弱、深度回撤），样本外稳定。
- 但**做空这些币亏钱或不显著**：流动性差、跌深的币经常暴力反弹，和下架公告后做空的逼空问题一样。
- 价值在**防守**：可作为名单/雷达上的风险标记。

## 四轮汇总：大模型在交易里的真实位置

| 大模型的角色 | 结论 |
|---|---|
| 直接判断买卖（盘中、新闻、写策略、治理提案） | 四轮全部没有优势 |
| 提出研究假设（研究循环 v2） | 运行中；目前 11 个公式均无增量，受限于可用数据 |
| 解析结构化事件（公告、代币经济） | 有用，但多数时候正则就够；真正的优势来自事件本身 |
| 风控与监控（下架防守、排期变更、熔断可见性） | 已落地，价值明确 |

真正站得住的收益来源都是**结构性、提前可知的事件**：新上市抛压、大额解锁前的抛售。
大模型的贡献是把这些事件**找到、读懂、持续监控**，而不是预测价格本身。
