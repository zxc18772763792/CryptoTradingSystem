# 币安中文群情绪：方法研究与条数版前向跟踪

2026-10-31，Asia/Shanghai。目的：将稀疏群聊观点转换为可解释、可核验的 BTC 方向观察，并用启用后的新样本验证它。语义分类质量和收益有效性分别评估。

## 网上方法与本项目选择

| 一手资料 | 方法与适用范围 | 本次采用方式 |
| --- | --- | --- |
| [SemEval-2016 立场识别](https://aclanthology.org/S16-1003/) | 区分对指定目标的支持／反对与一般正负情绪；未能判断不等于中性 | 指标定义为明确针对 BTC 的方向观点；不把 API 报错、开心、恐慌自动映射成多空。 |

| [FinChina SA，2023](https://arxiv.org/abs/2306.14096) | 中文金融实体级标注，独立标注者处理歧义；任务偏企业预警 | 借鉴目标和歧义分层；企业新闻准确率不外推成中文币圈群聊准确率。 |

| [VADER，2014](https://ojs.aaai.org/index.php/ICWSM/article/view/14550) | 社交文本词典及否定、程度等规则 | 它提示需要处理语言语境；本次没有把通用词典硬当中文币圈的方向分类器。 |
| [Antweiler 与 Frank，2004](https://onlinelibrary.wiley.com/doi/10.1111/j.1540-6261.2004.00662.x) | 论坛消息的方向、关注度和分歧分别研究；收益效应与波动效应有区别 | 分开展示方向分、观点密度、作者构成；不将聊天热度等同方向或将情绪等同可获利信号。 |
| [NIST：Wilson 比例区间](https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm) | 二项比例的区间描述，边界和小样本比简单正态近似更稳妥 | 对看多账号占比计算95% Wilson区间；明确账号相关性可能违反独立假设，该区间不是币价上涨概率。 |

这些资料支持方法选择，不证明本群、该币种或任何参数存在超额收益。最后一列是本项目的工程判断。

## 原始分类的小样本复查

对原归档做价格盲的分层复查：按固定哈希顺序查看10条方向标签、4条条件标签、4条描述标签、8条其他标签，只用于定位问题。复查由本次助手完成，不是独立人工金标，没有据此报告 precision、recall 或 F1。

观察到：只有数字目标的期待并不一定提供相对于现价的方向；长期投资与不确定未来的愿景不应直接服务6小时持有假设。条件句、问题、历史回顾和技术问题继续排除，未强行补成方向。

为独立条数版新增窄范围的保守筛查：

- 明确长期、定投或无确定近期时域的愿景暂不纳入；同时出现长短期限的文本隔离为歧义。
- 只有数字价格愿望、没有明确方向词的文本暂不纳入。不读取现价来猜测“目标价”是涨是跌。
- 只隔离，不反转或猜测替代方向；原冻结标签保持原样。

10:45 的存活归档快照中，104条原 BTC 方向候选保留93条：5条缺明确方向的价格愿望、5条长期观点、1条混合期限观点被隔离。该规则也可能误排真实观点，因此不称这些11条为“已证明的分类错误”。

## 新观察口径

以10条、20条经过上述筛查的 BTC 观点作为采样单位，每位作者只取该窗口内最新方向。同文复读跨账号只计一次。没有观点为 null，平衡观点才可为0。

方向分：`S = 100 × (看多作者数 − 看空作者数) / 去重作者数`。作者可能多个账号，去重不等于确认独立自然人。另显示 `S_shrink = 100 × (多 − 空)/(作者数+2)`，对应固定 Beta(1,1) 的描述性收缩，减少少样本的极端点估计；未据收益调参。

看多作者占比的95% Wilson区间用于显示样本不确定性，不作为币价胜率，也不包装成账号独立性已获验证。10条相对20条的差值只描述情绪变化，窗口有重叠，不当作额外独立样本。

每批至少5位去重作者、绝对方向分≥40才标为情绪候选。保留最新观点年龄和整窗跨度：最新观点超过6小时、窗口超过24小时均不再标为候选。这两个阈值是事先登记的操作约束，没有通过收益寻优。按条数采样去除了固定整点切分，并没有消除信息老化。

## 前向证据与原账本隔离

- 原始小时／六小时的四本聊天账、CryptoQuant账及其代码／协议指纹保持原样。新目录为 `data/research/binance_chat_sentiment_v2/`。
- 原归档只作明确标记的背景；启用后的新发表消息，且在当前连续覆盖段内、标签全部处理完成，才进入新前向流。覆盖重置后重新积累，不跨缺口拼批次。
- 以首次可用的复核结果追加脱敏衍生元数据；不保存聊天正文或引用。后续编辑／删除不重排已冻结的前向批次。研究方向或授权变化仍需按相应范围处理。
- 滚动10／20条用于观察；每个覆盖段的不重叠完整批次冻结纸面证据。未激活时，原采集任务不会自动初始化新版本。
- 10／20条各有顺势和反向账本；持有6小时、往返20bp及真实资金费，另记40bp成本压力和同入场做多对照。冻结之后至少60秒再取下一个5分钟边界，不回填过去入场。
- 每政策只允许一笔重叠纸面持仓；缺价格或资金费保持待结算，7天仍缺数据记不可用。四账本共享消息，样本不能相加为独立证据。
- 新模块、条数研究模块及原结算代码的实现指纹固定；源研究身份、协议、源检查点也核对。新观察器失败会单独显示，原有采集和账本继续运行。

## 验证要求与当前结论

先评估文本：需要独立人工、分层、价格盲的中文币圈标注，报告各类 precision/recall、方向错误及币种错配，单独处理反讽、否定、条件、长期愿景和复读。现有模型置信度尚未在本群校准；本轮规则测试不能替代此标注评估。

再评估交易：以固定参数积累至少100笔成熟前向事件和8个日历周，检查含资金费净值、成本压力、同入场对照和去掉最佳单笔后表现；按时间保留未来样本。若比较10/20条和顺／反多个方案，须处理多重比较及共享样本相关性。阈值满足后也只允许描述性筛查，`promotion_allowed` 始终为false。

本轮证明了观察与证据记录可以落地，没有证明盈利能力。背景快照在本版每人最新方向口径下，最近10条为−50分；看多账号占比区间约7.1%—59.1%，仍跨过50%均衡点。这比单看一个极端分数更能表达有限证据。
