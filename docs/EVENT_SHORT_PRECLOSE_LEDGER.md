# 事件做空账本 · 收盘前入场（event_short_preclose_v1）

前向纸面账本，只记录，不下单。规则全文在 [协议](../config/research_protocols/event_short_preclose_v1.json)，代码在 [账本模块](../core/research/event_short_preclose_ledger.py)。这两个文件按字节锁定，改动任何一个账本就停账；要改规则，得开新协议和新目录。

## 为什么要有这本账

2026-11-05 的账户级研究里，≥10% 解锁和 Upbit 韩元上币在同币其他时段的对照下都站得住。但这些都是样本内结果：事件优势是在同一段数据上发现的，≥10% 这条线和去掉韩国警示都是看过结果才定的。独立反驳还发现三件事：

- **韩元上币的收益有一块拿不到。** 日收盘后第一小时平均跌 2.17%（54 个留出事件，t=−3.75）。现有跟踪器按收盘价记入场，实际抓盘口却晚 3 到 28 分钟，那时中间价平均已低 2.58%。公告都比收盘早 12 小时以上，所以可以改在收盘前入场。
- **≥10% 解锁怕上涨行情。** 入场前 60 天前 30 指数涨超 15% 时，每笔只有 +0.58%（23 笔）。留出段又正好是山寨大跌。
- **解锁排期是否在 t−7 时已知，历史上证明不了。** 本地最早的排期就是 2026-09-27。

这本账用真实盘口价，从现在开始积累没有前视的样本。

## 规则

| 项目 | 规则 |
|---|---|
| 事件 | ≥10% 解锁（t−7 到 t−1）、Upbit 韩元上币（当天到 7 天后）。只从两个现有跟踪器读事件，不取它们的价格和收益 |
| 入场和出场 | 23:55:00–23:59:30 UTC 抓盘口，空币按买一价进、卖一价出 |
| 对冲 | 等额做多当时 24 小时成交额前 30 的永续（排除本币、稳定币、黄金代币和非币类合约），入场时冻结，卖一价进、买一价出 |
| 止损 | 小时线高点到 +40%，按该价或跳空开盘价再差 2% 成交；篮子到下一个窗口才平 |
| 资金费 | 实际结算。收盘前进场，所以算入场那次，不算出场那次；两条腿一致 |
| 成本 | 币腿往返 0.20%，篮子往返 0.10%，另按 1 万美元订单记平方根冲击（对应 20 万美元账户每笔 5%） |
| 作废 | 迟到、错过窗口、合约停止交易、同币已持仓都记为作废并单独统计 |
| 排期修订 | 每天存一份排期快照。解锁改期超过 3 天或规模跌破 7.5%：入场前作废；入场后下一个窗口平仓，收益照算 |

## 怎么判

同一入场日合成一批。满 30 个完整批次或 12 个月时判一次，只判一次；之前只作描述，不算 p 值。

| 判定 | 条件 |
|---|---|
| 未通过 | 批次均值 ≤ +2%，或篮子成员封顶 +100% 的版本 ≤ +2% |
| 部分判废 | 单个事件流满 15 笔且均值 ≤ +1%；或解锁改期、消失、迟到的比例超过 15%；或入场后上涨行情里的解锁满 10 笔且均值 ≤ 0；或前 15 笔韩元上币的入场价比当日收盘差 1 个百分点以上 |
| 未定 | 单侧检验 p > 0.05，或去掉贡献最大的 2 个币后每笔均值 ≤ +2% |
| 通过，但未覆盖上涨行情 | 以上都没触发，但入场后上涨行情里的解锁不足 10 笔（大概率如此） |
| 通过 | 全部满足 |

单笔亏损到 −70% 或已结算回撤到 −8% 时只告警，不停账。

按参照重抽 30 批估计：优势不变时约 75% 通过、5% 判废；优势减半时约 26% 通过、41% 判废；没有优势时约 2% 通过、90% 判废。
