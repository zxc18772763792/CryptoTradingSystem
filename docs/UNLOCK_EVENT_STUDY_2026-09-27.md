# 代币解锁事件研究（2026-09-27）

**问题**：7 月在山寨暴涨面板里测解锁，只有 17 个币、9 次拉盘，功效太低，结论只能是"没找到证据"。
免费数据源 DefiLlama 在那个宇宙里只覆盖 27/110 个币。这里换到 DefiLlama 自己的宇宙（370 个代币，有历史排期）
研究：**大额悬崖解锁前后，价格怎么走？**

复现：
```bash
python scripts/unlock_event_study.py        # 抓排期与 Binance 日线，事件表、价格缓存到 data/research/unlock_study/
python scripts/unlock_matched_control.py    # 同日历、同币龄对照（主结论）
```

## 方法

- 事件：DefiLlama `unlockEvents` 中的 cliff（一次性大块，不含线性释放）；规模 = 释放量 / 事件前已解锁量（流通量近似），≥1%；
  同一代币 30 天内只保留最大的一次。
- 价格：Binance 现货日线；按 DefiLlama 给的代码匹配，并要求 Binance 现价与 DefiLlama 现价相差 <15%（防止同名不同币）。
  370 个代币中 86 个有可用价格，937 个事件。
- **对照（主结论用）**：每个事件与"同一日历窗口、币龄相差 ±60 天以内、自己 ±45 天内没有解锁"的其他代币比较（中位 5 个对照）。
  同时去掉了大盘涨跌与"新币上线后普遍下跌"的影响。可匹配到 ≥3 个对照的事件 636 个（65 个代币）。
- 90% 置信区间按月聚类自助（解锁常集中在月初）。

## 被否决的两种做法（改方法前必读）

1. **以 BTC 为基准**：2024 ~ 2026 山寨整体跑输 BTC，几乎任何窗口都显示为负，夸大效应。改用研究代币的等权指数后，
   "解锁前 30 天" 从 −7.0% 降到 −1.9%。
2. **随机日期安慰剂**：要求离解锁 ≥45 天，对每月都解锁的代币只能落在上线初期等特殊时段；新币的安慰剂 30 天收益高达 +11%，不可用。

## 结果（相对同日历同币龄对照）

| | 前 30 天 | 前 7 天 | 后 30 天 | 全窗口（−30 → +30） |
|---|---|---|---|---|
| 全部（n=636） | −3.3% [−5.5, −1.5] | −2.0% [−2.9, −1.1] | −2.1% [−3.8, −0.4] | **−5.2% [−7.8, −3.0]**，67% 跑输 |
| 大额 ≥10%（n=71，37 币） | −14.9% [−20.4, −9.8] | −9.2% | −4.2%（跨零） | **−17.3% [−23.8, −10.4]**，82% 跑输 |
| 1 ~ 3%（n=332） | −2.3% | −1.1% | −1.9% | −3.8% [−6.4, −1.0] |
| 3 ~ 10%（n=233） | −1.3% | −1.1% | −1.8% | −3.7% [−8.3, +0.6] |
| 币龄 ≤1 年（n=270） | −4.8% | −3.0% | −2.9% | −7.7% [−12.1, −3.6] |
| 币龄 >1 年（n=366） | −2.2% | −1.2% | −1.6% | −3.4% [−6.2, −0.5] |

## 解读

- **效应真实且在控制币龄、日历之后仍然存在**，并且大部分发生在**解锁之前**——排期是公开的，市场提前定价（对冲、做空、提前卖出）。
- 规模越大越明显：≥10% 的大额解锁在前后 60 天里平均跑输对照 17%。
- 非团队解锁（生态、空投）效应反而不弱于团队解锁：空投接收者往往直接卖出。
- 与 7 月结论不矛盾：7 月测的是"解锁能否预测**暴涨**"（样本极少）；这里测的是"解锁前后的**相对收益**"，样本大一个数量级。

## 局限

- **幸存者偏差**：只含今天仍在 DefiLlama 索引且仍在 Binance 现货交易的代币；已下架的币（多半表现更差）不在样本里，事件组和对照组都受影响，方向不确定。
- **排期可能被事后修订**：DefiLlama 的排期是现在整理的，历史上被推迟或取消的解锁可能按"原计划"或"实际"记录，未逐一核对。
- **可交易性未验证**：结论是相对收益；实际做空需要永续合约、承担资金费率与两腿成本。下一步应做"t−30 做空、t+30 平仓、对冲等权篮子"的回测，计入资金费率。
- 大模型在这里不是必需的：排期来自结构化数据。大模型能扩展的是**覆盖面**——为 DefiLlama 没有排期的代币从白皮书/公告中提取解锁计划。
