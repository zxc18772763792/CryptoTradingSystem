# 自主研究闭环

`core/ai/autonomous_research_loop.py` 保留原公开入口，版本 2 的实现拆分为
`research_loop_service.py`（状态、调度、反馈、观察）和
`research_loop_evaluation.py`（数据就绪、程序约束和有限回测）。

## 工作流程

1. 按配置轮换币种和周期。检查 Binance、Gate 已收盘 OHLCV 的新鲜度、覆盖率、连续性和共同窗口价格一致性。
   短窗口自动扩展至至少约 240 根样本，实际天数返回在 `data_readiness.effective_days`；例如 4h 最少使用 41 天。
2. 缺数、过期或有缺口时，用独立公开行情客户端补数。每个补数任务最多两次尝试、总计 90 秒，最多 20,000 根。数据未就绪不调用模型、不消耗模型轮次。
3. 将最新市场摘要、历史摘要、最近四轮同币种同周期的程序/实测指标/淘汰原因，以及新增行情观察结果传给模型。模型需结合失败原因修改程序，并保留不同思路。
4. 每轮最多评估三个固定程序，不进行隐藏参数网格搜索。每个程序预留三次回测：前 70% 训练、跳过一根后余下的开发验证、验证段双倍成本压力测试。单个无效程序不拖垮其他草案。
5. 记录所有候选、淘汰原因、实验及反馈。通过历史门槛的程序冻结，进入新增行情观察；同币种同周期最多同时观察三个程序，重复或超额候选只保留研究结果。
6. 观察仅使用开盘时间不早于冻结时刻、且已经收盘的新 K 线。达到门槛后产生优胜候选。挑战者与现任候选必须在相同新增行情窗口比较。行情异常、风险失败、到期或等待重算时撤下推荐。
7. 后续研究读取上述实测反馈，持续改进假设；没有合格结果时明确保留空推荐。

最新市场摘要和开发验证都会参与选择。因此历史验证不被标成独立样本，也不填充候选的 OOS 分数；只有冻结后的新增行情可以填写该分数。观察仍有有限样本与反复选优的局限，不代表未来收益保证。

## 默认门槛与预算

| 配置 | 默认值 |
| --- | --- |
| 研究范围 | BTC/USDT、ETH/USDT，1h，最近 30 天 |
| 调度 | 每小时最多一轮，每个 UTC 自然日最多六轮 |
| 模型尝试 | 进入生成阶段即记账，失败也保留；手动运行不绕过每日上限 |
| 模型请求超时 | 每个通道默认 180 秒，可配置 30–300 秒；整轮生成阶段上限为两倍通道超时加 30 秒 |
| 研究回测预算 | 每轮最多 24 次；当前最多三个程序、每个三次，实际最多九次 |
| 观察计算预算 | 每次调度另外最多 24 次；同一新收盘 K 线不重复计算，轮换处理观察队列 |
| 观察补数预算 | 每次调度最多两个币种/周期，每个任务十分钟冷却 |
| 基础费用假设 | 单边手续费 0.04%，滑点 2 bps；压力测试两者翻倍 |
| 历史门槛 | 训练净收益为正；开发验证净收益为正、至少五笔完整交易、回撤不超过 10%、Sharpe 不低于 0.5、数据质量正常；双倍成本净收益为正 |
| 新增行情观察 | 至少 72 根和五笔完整交易，沿用净收益/回撤/Sharpe 门槛；最长 30 天，到期重新研究 |
| 挑战者替换 | 同窗口净收益改善超过 0.2 个百分点，回撤最多增加 0.5 个百分点，且挑战者通过门槛 |

这是现有做多/空仓 DSL 的研究模型，使用 `price/sma/ema/rsi/zscore/returns` 指标；不代表已覆盖做空、杠杆、资金费率、盘口容量或真实成交约束。每日模型预算耗尽后，已有候选的观察继续运行。关闭循环后停止后续调度；运行中的生成/验证结果通过配置版本检查阻止发布。

## 操作与恢复

- AI 研究页显示循环状态、实际完成轮次、淘汰原因、观察进展与当前优胜候选。
- `GET /api/ai/research-loop` 返回状态；`PATCH` 修改配置；`POST /api/ai/research-loop/run` 运行一轮。写接口沿用 `manage_ai_research` 权限。
- 每日预算在北京时间次日 08:00 重置。重启保留旧失败记录和已消耗次数，未完成提案会标记中断。
- 状态保存在原 `data/research/ai/autonomous_loop.json`，采用临时文件替换写入；候选与实验复用现有注册表。
- 模型认证、额度不足、限流、超时、无效 JSON 和程序错误分别报告。原始服务商错误正文不写入新错误日志或状态，避免暴露账户信息。
- Responses 请求采用流式传输并复用现有 SSE 解析器，明确传递 `reasoning.effort=low`（封装器会忽略不支持的 `none`）；循环默认要求一至两个精简草案，避免重复描述增加网关等待时间。完整内容返回后才开始程序校验与回测。
- 本循环只研究和推荐，不自动注册策略、不启动交易。原有人工研究和部署流程保留。
- 服务操作使用 `web.bat stop` / `web.bat start` / `web.bat status`。
