# 大模型交易：第五轮研究——代币供给通胀因子（2026-09-27）

复现：`python scripts/unlock_event_study.py`（缓存价格与排期）→ `python scripts/supply_inflation_factor.py`

## 问题

解锁事件研究发现"≥10% 的一次性大额解锁"会压价格。更一般的问题：**未来 90 天按公开排期新增的供给越多，
下一段时间的收益是否越差？** 这包括线性释放，每个币每个月都有值，样本比事件多得多，而且**提前完全可知**。

## 方法

- 宇宙：DefiLlama 排期 × Binance 现货价格，每月约 45 个代币（共 85 个），2023-01 ~ 2026-06，42 个月。
- 因子：月初时点，排期显示未来 90 天已解锁量增长比例（中位 7.5%，前 10% 超过 26%）。
- 收益：扣除当月样本等权平均；多空 = 做多低增长三分之一、做空高增长三分之一，持有 30 天，扣 0.4% 成本。

## 结果

| 检验 | 结果 |
|---|---|
| 月度多空（30 天） | **+2.6%/月**（中位 +4.4%），76% 的月份为正，90% CI [0.0, +5.0] |
| 秩相关（供给增长 vs 下月收益） | 均值 −0.16，**42 个月中 33 个为负**（符号检验 p = 0.0001） |
| 按币龄分三组后组内秩相关 | −0.15，34/42 为负（p < 0.0001）——不是"新币效应" |
| 按市值分三组后组内秩相关 | −0.16，33/42 为负（p = 0.0001）——不是"小市值效应" |
| 季度不重叠持有（90 天） | **+14.8%/季度**，14 个季度中 13 个为正 |
| 剔除当月有 ≥10% 大额解锁的币 | +1.8%/月，秩相关仍 79% 月份为负——线性释放本身也有效 |
| 分时段 | 2023–24 +3.1%/月，2025–26 +1.9%/月 |

月均值的置信区间偏宽是因为少数极端月份；**逐月方向的一致性**才是最强的证据。

## 解读

这是五轮研究里**最稳健的结果**：新增供给需要买盘承接，而排期提前公开，市场没有完全定价。
它和"大额解锁前做空"同源，但覆盖面更广（每个有排期的币每月都有信号）、更适合组合化（多空对冲）。

## 局限

- **幸存者偏差**：只含今天仍在 DefiLlama 索引且在 Binance 现货交易的代币。
- **排期修订**：用的是 DefiLlama 现在的排期；历史上的延期/加速未逐一核对。
- **宇宙小**：每月约 45 个币，主要是有 VC 排期的中大市值代币；小市值妖币多数没有排期。
- 这是样本内结论，需要前向验证。

## 大模型在这里的角色

优势来自排期数据本身。大模型能扩大这个优势的地方是**覆盖面**：DefiLlama 只覆盖周度伏击名单宇宙中 27/110 个币。
若能从项目文档中可靠提取排期，就能把因子扩到更多币。但可靠的文本来源是瓶颈：白皮书多为来源不可信的 PDF（不宜自动下载），
CoinGecko 描述通常不含排期，专业数据商收费。这一步需要先解决数据源。
