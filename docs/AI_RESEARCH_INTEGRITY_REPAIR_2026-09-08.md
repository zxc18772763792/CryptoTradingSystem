# AI 研究记录与调度修复

本次核实到正式研究目录中存在测试候选 `cand-test-trigger`，以及测试函数返回的固定报告路径 `research_ops.csv`、`research_out.csv`、`research_bg.csv`。不能将这些记录的收益指标作为真实回测结果。

## 已处理

- 测试收集阶段将交易数据库、新闻数据库和默认数据目录指向临时目录；每项测试再隔离研究输出和反馈先验文件。
- 规则规划器使用 `source=rule`、`llm_used=false`；接收通过校验的 LLM 研究输出后才记录 `llm_guided`。配置模型与实际提案来源分别显示。
- CUSUM 替代研究按原候选去重，使用候选真实币种和周期，自动进入回测队列。失败后需人工重试，不每五分钟重复创建。此路径仍是规则模板研究，不是持续自由研究，也不自动部署。
- 调度器检查完整队列，避免较早的排队研究被最新 50 条草稿遮挡；尚未分配任务的自动替代提案跨重启保留。
- 启动恢复 AI 策略时检查候选存在、状态有效及提案/实验关联一致。原始交易数据库记录保留，失去研究来源的记录不会自动恢复运行。
- 页面展开运行降级的来源和原因，显示快照时间；刷新失败保留旧值时显示“数据已过期”。不会通过隐藏异常把降级数量归零。

## 备份与隔离

备份目录：`data/research/quarantine/20260908T043318058090Z`。包含原始注册表、`latest.json` 和 SHA-256 清单。

隔离 356 个提案、15 个候选、520 个实验、520 条实验运行及 13,769 条关联生命周期记录。保留 3 个无法认定为测试污染的实验及运行。仅依据明确的测试文件名和关联 ID，不按策略名称、日期或收益指标删除。

可复查工具：

```powershell
python scripts/quarantine_research_test_data.py
```

默认仅预览；`--apply` 要求 Web 服务已停止，并在修改前保存完整备份。恢复时先停服务，再按备份目录中的相对路径恢复文件；恢复完整旧备份也会重新引入测试污染。
