# 研究跟踪器改进（2026-10-20）

本次落实跟踪器计量修正、事件风险影子、反转配对评估、Coinglass 四格归因。全部属于研究纸面记录，不产生交易订单。原策略选择、入场价格、已结算收益和冻结退役规则保留作基线。

## 1. 统一展示经济含义

- 解锁空头价格浮盈改为 `1 - last / entry`。旧的无版本 `entry / last - 1` 在读取视图转换一次；新标价带 `mark_formula_version=2`。读取不改文件，不转换历史已结算收益。
- 反转过滤影子的判定均值是同日“影子减原版”，明确显示为**百分点/天**，另列影子自身收益和同期原版。
- 反转按多空总名义金额计；七日组合、解锁和事件对冲按单腿名义金额计，折算总名义金额除以二。策略页移除易被误认成账户收益的累计列，改为统一分母后的均值，仍不作不同持有周期的收益排名。
- 在持标价注明价格时间及范围；未计对冲腿时不显示成完整组合净浮盈。旧价没有时间戳时明确缺失。供给因子单独注明尚未计借币可得性及借币成本。

## 2. 事件空头的前瞻风险影子 v1

每个事件账本在 `event_risk_shadow` 下保存独立配置、登记时间、排除的历史源 ID 和影子记录。登记必须先落盘。历史已入场/已结算交易不回填；已知但尚未到入场时点的未来信号仍可参与。

首笔前冻结的风险预算：

| 项目 | v1 规则 |
|---|---|
| 预计不利资金费 | 剩余持有期投影不超过单腿名义金额的 2% |
| 含费总亏损触发值 | 价格盈亏 + 已结算资金费 − 入场/退出成本 ≤ −10% |
| 模拟成交 | 入场空头卖 bid，买回 ask；对冲多头相反；每次成交再计 10bp 不利滑点 |
| 手续费 | 每次成交名义金额的 0.05%，退出按实际价格比例计 |
| 入场观察窗口 | 基线预定入场时点后 15 分钟；缺数据或超时独立记录，不用后来的费率补写入场 |
| 报价新鲜度 | 含交易所时间戳；超过 30 秒或盘口交叉标不可用 |

2% 和 10% 是事先选择的圆整风险预算：资金费最多消耗亏损预算的五分之一，**不是从 GTC 等已发生交易优化得到的最佳参数**。费率投影将入场时已知的不利费率保持到预定退出，是情景估算，不是预测或上界。不将有利资金费抵销其他腿的不利费用预算。

资金费使用合约实际间隔元数据；无配置时要求可核对的结算时间戳推导，不默认八小时。已结算现金按各笔结算标记价格/入场价格折算。缺失标记价、费率、尾部或中间结算覆盖时保持未知，不能按零计费。独立网络请求限制并发，并在读取资金费后获取新鲜报价。

总亏损是**检查时触发条件，不是保证不超过 10% 的止损价**。中央串行研究调度器约每五分钟观察已知信号和已有风险仓位，先于耗时研究任务；公告跟踪器由自己的约九十秒循环观察。停机、超时和行情跳变均可能造成超额亏损。检测与模拟成交分别记录时间；发生跳空时按新观察报价模拟退出，不伪造早先的理想止损成交。费用未发布时可先冻结退出报价，保持待资金费结算状态并重试。

覆盖韩国警示/上币、解锁、币安公告、新永续上市。公告由独立 worker 独占其文件，中央监测不重复写。其余监测与基线在同一串行研究 pass 中运行，避免覆盖状态；可选影子出错不阻断基线。源记录消失仍管理已开的影子，已知信号取消/失效时在下一次可观察报价退出。

### 比较边界

影子使用实际观察时的盘口与独立成本，入场可晚于基线日线收盘。解锁影子的篮子在入场前的排期检查中冻结，原基线在其入场检查时选篮子；两者可不同。必须保留冻结时间、源 ID、入场延迟及两腿明细，不能把全部收益差解释为风险预算的因果效果。风险影子不参与原策略的退役判定。

## 3. 反转过滤配对评估

`summary.paired_evaluation` 只匹配相同日期、入场区间且已结算、非迟到/回填的两版结果。显示自身均值、增益、正收益天数及共同日期，不把每个币或两个版本当独立样本。

- 周聚类、七日滞后 Newey–West 敏感性：至少 32 个共同日、8 个日历周组，且无已知每日持有重叠；稀疏日期覆盖也会限制 HAC。使用按周数的小样本 t 系数。仅为敏感性，不产生新确认结论。
- 去掉最佳增益日、双方共同增加成本、影子单独增加成本的对照。
- 拆分剔除原多头、替换币、共享持仓权重变化的价格与资金费贡献；缺腿不编造归因。
- 新形成记录增加信号就绪、报价观察、过滤就绪时间；旧记录时间未知。最后成交价的漂移诊断不冒充 bid/ask 成交收益。

保持原版和 20% 爆仓过滤规则，不新增其他过滤条件。

## 4. Coinglass 四格归因

只读分析已有的 131 币 IC 加权/等权与 234 币 IC 加权/等权，不重复创建策略。每种权重差、扩池差按共同已结算信号日比较；四格主效应和交互项只使用四种都有结果的日期。

显示多空价格、资金费、成本、换手及形成/结算时间差。成本压力从每腿来回 0.12% 提高到 0.20%；满换手两腿额外拖累 **0.16 个百分点**。不完整持仓结算排除于可比组合，缺失归因保留空值。七日持有重叠，按结算周分组仅能部分处理依赖，少于两个周组不生成区间。原池/扩池入场时间不同，扩池差混合了时间效应，不称为纯扩池 alpha。

入口：策略页跟踪器下方的配对与归因明细、研究页对应卡片；只读 API `/api/ai/research-trackers` 的 `diagnostics` 和 `/api/ai/coinglass-attribution`（实际前缀随应用路由配置）。
