# Coinglass 七日组合可执行性核查 · 2026-11-05

机制上可用币安 USDT 永续执行，不需要现货借币。但现有跟踪器是纸面账本，没有对应的实盘组合执行器。以下用原版为主，月度换池版单列；不是下单建议或账户保证金验收。

## 最新研究结果

原版18期完整结算，7期在持，均值+0.572%/期，胜率44.4%，90%描述区间[-0.51%,1.66%]，仅3个结算周组。收益以单腿名义金额为分母，按多空总名义金额折算约+0.286%/期；重叠组合不能相加当账户收益。最低364期的原判定门槛未满足。

更正后的历史回测约+0.10%/期；将成本参数从0.12%提高至0.20%后约为-0.02%/期。此处沿用更正后的研究和原成本定义，不使用原先高估空头的对数收益结果。

## 执行差距

- 需要独立保存7个分期账本，再形成每币净目标；交易所的单向或双向仓位不等于7份研究账本。不能用“全平某币”来退出其中一期。
- 手续费按实际成交额和账户费率，滑点按盘口/成交记录计算。当前成本只按更换成员占比估算，未完整覆盖保留成员的数量调整和舍入。
- 当前盘口快照有部分币买卖差约9至12bps；最优档数量不能证明整笔成交价。本次没有做深度或冲击成本保证。
- 旧资金费按费率相加，不是每腿固定合约数量按结算标记价折算的完整现金流。
- 现有逐腿结算会保留各自退出观测时刻，重试时不同腿未必严格同时持有7天；需要统一的执行与费用边界。
- 还需账户模式、保证金、裸露腿、故障补偿、幂等和持仓对账验收；本次未修改任何账户模式，也未启动实盘。

结论：可以研究和实现净额组合执行，但当前不宜把纸面跟踪器直接切到实盘。当前18期收益仍不足以证明扣除实际执行成本后有稳定优势；月度版尚无成熟样本，更不能作为已验证替代版。
