## Alastar 前置修复

原链路能及时收到新帖，但没有自动语义解释器，消息会因无人解释而超时。现已添加受管任务 `alastar_signal_intake`，使用用户确认复用的新闻模型主备配置，只处理首次启用后发布、及时收到且保持未编辑的公开文字。输入逐字引句、币种、方向、置信度及语义标志均有本地校验；条件分析、更新、宣传与双向不明结果只留回执。

自动解释输入和模型证据先落盘，再逐个调用原v2/v3的 `freeze(label)` 校验器，保存逐账本冻结记录和准入/剔除状态。暂时锁忙可重试，部分成功从原journal恢复，不重复推理或冻结，不把文件投递当作成功。原v2/v3源码、冻结协议及既有账本没有迁移或改写，原时效、时钟、仓位、收益统计门槛仍适用。人工CLI/旧inbox保留；旧inbox本身的锁忙永久拒绝行为未通过改写冻结实现处理，新的自动链路已绕开这个边界。

初次任务启用：北京时间 **2026-10-23 19:55:13**。首次部署阶段231项相关回归通过，之后才启动团队。457和458均早于自动解释器启用，未追认入场。真实模型诊断成功，`gemini-2.5-flash` 将457判为 `ambiguous`，没有向账本提交。

操作及付费范围证据见 [Alastar接入说明](../../docs/ALASTAR_SIGNAL_ACCESS_20261023.md)。已确认公开频道仍可读取，PumpGlass Pro是另一个收费数据提醒产品；Alastar Private Access存在，但其当前价格和私享覆盖范围未确认。

## 团队另外确认并修复的11类缺陷

| 范围 | 触发问题与最终行为 |
|---|---|
| 订单状态 | 已成交/拒绝/过期/已撤销订单再次撤单会回退状态或重复回调；现在仅OPEN订单可进入撤单路径，保留部分成交事实。 |
| 策略预算 | 资金分配为数字或字符串0时，被当作全额或跳过额度检查；现在阻止新增仓位，正常减仓退出仍允许。 |
| 风控更新 | 非有限数或后续字段错误可留下部分生效的风险参数；现在先完整验证再统一应用，合法0值及原归一化语义保留，API将校验错误返回400。 |
| 止损权限 | 策略管理权限通过OR逻辑旁路风险审批；共享止损策略写入口现在要求风险审批权限。 |
| 通知零资产 | 显式资产0被旧快照覆盖，可能漏报低资产；现在只在未提供/None时回退。 |
| 通知非法数值 | NaN/Infinity先进入评估再造成序列化500；现在请求校验返回422，评估不执行。 |
| 通知事件窗口 | 1000条滚动缓冲区满时，通过列表长度截取会丢新事件；现在按发送前对象身份识别新事件。 |
| Telegram内存 | 消息ID缺口先完整分配再截断，可能耗尽采集内存；现在构造前就限制为最多100个。 |
| Telegram日期 | 极端带时区日期转UTC溢出会丢整页；现在跳过坏日期帖子并继续处理。 |
| 解释器健康 | 失败冷却期间误报恢复、禁用仍报活跃、失败候选编辑移出后永久报错；现在按未决状态、启用开关与实际队列恢复健康，保留已提交回执。 |
| 冻结投递 | 原自动inbox投递可因短暂文件锁被永久拒绝；新路径直接调用原冻结器，持久化提交回执，支持部分提交、提交后回执写失败及旧自动标签迁移。 |
